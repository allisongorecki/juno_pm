## What graders score

- **What you’re scoring:** Generate a list of feature request tickets based on internal slack threads, jira tickets, support tickets and notion docs updated in the past week.
- **Value proposition:** Ensure the tickets are based on a real reference source. Ensure that the same issue mentioned across channels is combined into one feature request ticket.

## Dimensions

| Dimension | Question | Scale | 1 or No | 3 | 5 or Yes |
|---|---|---|---|---|---|
| Accuracy (deal-breaker) | Does each ticket come with a reference to a source | Yes / No | At least one feature request ticket is invented or can’t be traced. | n/a | Every feature request ticket traces to slack message feed, notion document, or jira ticket generated in the last week.  |
| Sources | Does every feature request ticket link to the message or ticket it came from? | Yes / No | One or more feature request has no source, or the link is wrong. | n/a | Every feature request has a working link to its source. |
| Summarised | Is the same issue or need from different sources summarised in the same feature request ticket.  | Yes / No | There are duplicate or feature request tickets with a very similar description.  | n/a | There are no duplicates of feature requests that week, nor when compared to the weeks before (up to 4 weeks ago).  |
| Private data | Does it avoid exposing personal or confidential details? | Yes / No | Assessment and documentation of customer behaviour, attitude, and opinions should not be included in the feature request ticket.  | n/a | Customer contact and contract details can be included to help assess impact.  |

## Calibration

- **How many answers you’ll score, and how often:** 10 summaries a week, including the ones I felt least sure about
- **Who scores them with you:** Me, plus one other PM once a month
- **What happens when two of you disagree:** If our scores differ by 2 or more on any question, we talk it through and rewrite that description so it’s clearer next time.

## Pass bar

Every yes or no question passes

**Fails outright, whatever the average:**

- Accuracy: any "no"
- a hallucinated reference
